# GEN-RSI

Static GitHub Pages entry point for the VIGA Selected 14 comparison gallery.

The page is self-contained except for the generated videos and reference frames, which remain on the existing public OSS preview path so the GitHub repository stays lightweight.

## GitHub Pages

The repository includes a Pages workflow under `.github/workflows/pages.yml`. After creating the repository, set **Settings -> Pages -> Source** to **GitHub Actions** if GitHub has not enabled it automatically.
